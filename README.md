## 我在分享什么

- **概率论与数学直觉**：从具体问题出发，理解概念、推导和知识之间的联系。
- **大模型原理**：用纸笔和具体例子讲解Transformer、MoE、浮点数、Softmax等内容。
- **算法工程师的成长**：分享学习路线、实习、项目与职场经验。

另有两部书稿已交稿，分别围绕大模型算法工程师的学习与实践、算法工程师的职场观察。出版进展会在B站和知乎同步。
