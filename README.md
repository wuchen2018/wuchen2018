## 我在分享什么

- **概率论与数学直觉**：从具体问题出发，理解概念、推导和知识之间的联系。
- **大模型原理**：用纸笔和具体例子讲解Transformer、MoE、浮点数、Softmax等内容。
- **算法工程经验**：分享学习路线、实习、项目与职场经验。
