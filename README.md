# 你好，我是武辰 · Wu Chen

我高中读文科，本科在武汉大学学金融，研究生转到数学与统计，后来做了约六年算法工作。现在我在知乎写概率论和数学直觉，在 B站用纸和笔讲大模型。

我讲东西，喜欢从一个具体的问题开始，**用大白话讲，不跳步**；能手算的地方，就带你算一遍。我自己很多东西是靠自学的，知道自学的人会卡在哪里，所以不管写书还是做视频，我都会先想：读到这里，你会不会卡住？

### 《一个大模型工程师的诞生》

**清华大学出版社审校中**

写给想做大模型算法工程师的人。从计算机基础和必要的数学讲起，一路讲到 Transformer、微调、RAG 和部署；后半本写数据、协作和求职，这些是入职以后每天都要面对的事。

[书稿目录与八份样章](https://github.com/wuchen2018/llm-engineer-book) · [我为什么写这本书](https://wuchen2018.pages.dev/articles/llm-book-preface.html)

### 《收到：一个算法工程师的六年》

**书稿已交清华大学出版社 · 尚未出版**

书名《收到》，是我做算法工程师六年里打得最多的两个字。这本书写的就是这六年，一半是我自己的经历，一半是别人的故事。它不讲技术，讲做这份工作的人。

[我为什么写这本书](https://wuchen2018.pages.dev/articles/received-preface.html) · [图书介绍](https://github.com/wuchen2018/algorithm-engineer-book)

出版进展会在这里、B站和知乎同步。
